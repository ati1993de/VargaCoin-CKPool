# Public release checklist

- [ ] `README-UPSTREAM.md` is present.
- [ ] Upstream license/copyright files are preserved.
- [ ] No production RPC credentials are present.
- [ ] No wallet seed, private key, wallet file or `.cookie` is present.
- [ ] No production logs, PID files or backups are present.
- [ ] No private/internal infrastructure information is present.
- [ ] Public examples contain placeholders only.
- [ ] `git diff --check` passes.
- [ ] Clean build from the public tree succeeds.
- [ ] Mainnet-specific values have been independently verified.
- [ ] Repository contents have been manually reviewed before `git push`.
